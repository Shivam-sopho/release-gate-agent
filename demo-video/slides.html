How the agent works

From a binary diff to a human decision.

01

Diff

Compiled APKs: manifest, dex string pool, per-class hashes. Not the source.

→
02

Plan

Which journeys does this change put at risk? Upgrade + fresh-install control.

→
03

Test

Drives a real emulator on both builds. Recovers when the device fails.

→
04

Verify

Verdict needs device evidence: screenshots, screen state, logcat.

→
05

Human gate

Report + fix in code. The release waits for Allow / Deny.
